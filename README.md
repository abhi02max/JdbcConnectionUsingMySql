# JDBC Connection with MySQL

A Java exercise demonstrating relational-database connectivity and SQL execution through JDBC.

## Technology

Java · JDBC · MySQL · Maven

## Demonstrated skills

- Establishing a database connection
- Executing SQL statements
- Reading result sets
- Managing database resources
- Separating credentials from application logic

## Run

Configure a local MySQL database and update the connection values expected by the source code, then run:

```bash
mvn clean test
```

Do not commit real database credentials.
